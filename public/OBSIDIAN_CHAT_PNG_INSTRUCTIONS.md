# ObsidianChat PNG Image Instructions

## Required Action

You need to place your ObsidianChat branding image in this directory.

**File Requirements:**
- **Filename:** `obsidian-chat.png`
- **Location:** `/public/obsidian-chat.png`
- **Recommended Dimensions:** 480px width × 160px height (or similar aspect ratio)
- **Format:** PNG with transparency support
- **Purpose:** This image will be displayed on the sign-in/authentication page

## Where It's Used

The PNG image is displayed in:
- Auth layout (`src/app/(auth)/layout.tsx`) - Shows on the left side of the sign-in page on desktop

## What to Do

1. Create or obtain your ObsidianChat logo/branding PNG image
2. Save it as `obsidian-chat.png`
3. Place it directly in the `/public/` directory
4. The application is already configured to use it - no further code changes needed
